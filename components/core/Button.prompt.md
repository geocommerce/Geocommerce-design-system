Pill CTA used everywhere on the Geocommerce site — hero, section ends, forms.

```jsx
<Button variant="primary" size="lg" href="/contact" iconRight="→">Start Your Project</Button>
```

Variants: `primary` (green fill), `secondary` (ink outline that inverts on hover), `ghost` (bare), `inverse` (white on green/dark sections). Sizes sm/md/lg map to 36/46/56px. Site copy uses title case with a trailing `→` on secondary links.
